🔐 SECURITY FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ JWT Authentication
   └─ All requests require valid JWT token in Authorization header

✅ Role-Based Access Control
   └─ All endpoints require "admin" role

✅ Rate Limiting
   ├─ Global: 100 requests per 15 minutes per IP
   └─ Admin: 5 requests per 15 minutes per IP

✅ Password Security
   ├─ Bcrypt hashing (12 salt rounds)
   ├─ Minimum 8 characters
   ├─ Requires uppercase, lowercase, number
   └─ Never returned in API responses

✅ Input Validation
   └─ Joi schemas for all request bodies

✅ Soft Deletes
   └─ No permanent data loss, recoverable from backups

✅ Error Handling
   └─ Comprehensive error messages & status codes
